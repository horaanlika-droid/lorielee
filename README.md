# Лори Ли. Дорога домой

Русскоязычный подкаст о жизни Лори Ли по биографии Валери Гроув, лежащей в репозитории. Спокойный разговорный рассказ, без космоса, эзотерики и квантовой физики. Это авторский пересказ, а не полный перевод книги.

> **Идёт переозвучивание выбранным пользователем мужским синтетическим голосом.** Новый полный выпуск ещё не смонтирован. До завершения всех раундов `lorielee_full_podcast.mp3` содержит **предыдущую озвучку** длительностью 59 минут 43 секунды. Она будет заменена только после готовности и проверки всех новых фрагментов.

## Новая озвучка: прогресс

- Голос выбран в этой беседе: **`voice-00`**, русский язык. Использовать его для всех фрагментов; повторный выбор голоса не нужен.
- Сценарий сохранён без сокращений и переписывания. Читается только текст под заголовками глав, без вступительной служебной заметки и Markdown-заголовков.
- План: **36 фрагментов**, каждый не длиннее 1500 символов, разрезан по границам предложений и глав. Полное покрытие сценария и его SHA-256 проверяются скриптом.
- **Готово: 11 из 36 фрагментов (001–011), около 14 минут 1 секунды исходного аудио.** Это главы 1–3 целиком и начало главы 4; ещё не единый выпуск.
- Фрагмент 001 — ранее созданная проба `lorielee_voice_preview.mp3`; повторно его не генерировать. Остальные записи находятся в [`podcast_revoice/`](podcast_revoice/).
- Точные тексты, порядок, пути файлов, длительности и контрольные суммы: [`podcast_revoice/plan.json`](podcast_revoice/plan.json).

## Задание агенту на следующий раунд

**Продолжить с фрагмента 012, не начинать заново.**

1. Прочитать этот README и `podcast_revoice/plan.json`. Не изменять сценарий, выбранный голос, порядок фрагментов и уже готовые записи.
2. Если окружение нужно восстановить:
   ```bash
   python -m venv .venv
   .venv/bin/python -m pip install -r requirements-audio.txt
   ```
3. Проверить план и получить точные тексты следующей партии:
   ```bash
   .venv/bin/python scripts/revoice_podcast.py status --batch 10 --show-text
   ```
4. Озвучить **012–021** через `generate_speech`, не более 10 вызовов за ответ. Брать `text` и `file` дословно из плана, указывать **`voice_id: "voice-00"`**. Для `file_path` использовать путь внутри `/home/user/lorielee/`, указанный в плане. Один фрагмент — один вызов; независимые вызовы можно выполнить параллельно. Не вызывать `add_voice` повторно и не подменять выбранный голос локальным синтезатором.
5. Проверить, что новые MP3 декодируются без ошибок. Выполнить `status` ещё раз: он сохранит в плане статусы, реальные длительности и SHA-256 аудиофайлов.
6. Обновить этот README: фактически готовые номера, количество и длительность, состояние раунда и **точное задание на следующую партию**. При ошибке продолжать с отсутствующих файлов, не пересоздавать успешные.
7. До готовности всех 36 фрагментов не заменять старый полный MP3 и не объявлять новую версию завершённой.

## Финальный монтаж — после всех раундов

Когда `status` подтвердит **36/36** готовых фрагментов:

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/revoice_podcast.py assemble
```

[`scripts/revoice_podcast.py`](scripts/revoice_podcast.py) соберёт все фрагменты по плану в **один файл `lorielee_full_podcast.mp3`**:

- фрагменты декодируются в единый PCM-поток, без повторения первой пробы;
- между главами добавляются паузы 1,2 секунды;
- звук приводится к моно, 24 кГц, MP3 128 кбит/с, целевой громкости −18 LUFS и true peak −1,5 dB;
- в MP3 записываются названия и позиции 12 глав;
- полный файл проверяется декодированием и заменяет прежнюю запись **только после успешной сборки**;
- реальные таймкоды сохраняются в `podcast_revoice/chapters.json` и в разделе `assembly` плана.

**Завершая работу:** обновить ссылки, длительность и таблицу навигации ниже по фактическим новым таймкодам; убрать предупреждение о предыдущей озвучке; отметить раунды и монтаж завершёнными; открыть пользователю именно итоговый полный MP3. Не представлять отдельные фрагменты как полный выпуск.
